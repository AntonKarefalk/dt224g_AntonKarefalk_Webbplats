# Projekt - Webbsida för No.15 S & Friends
Detta projekt är en webbplats för frisörsalongen No.15 S & Friends i Örnsköldsvik. Syftet med webbplatsen är att ge besökare information om salongen, dess tjänster och öppettider samt göra det möjligt att testa ett enkelt bokningsformulär.
Webbsidan: https://antonkarefalkwebbplats.netlify.app/
